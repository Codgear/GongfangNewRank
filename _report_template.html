① 加分项 add —— 衡量"当前价值"

三项正向指标先做 log(1+x) 对数压缩，再在当日全部玩法内做 min-max 归一化，最后加权。对数压缩避免大体量数值主导、缓解长尾。

add = 0.35·norm(ln(1+N_new)) + 0.25·norm(ln(1+N_ret)) + 0.40·norm(ln(1+Rev))
指标权重含义
N_new 近7日新进0.35拉新能力
N_ret 近7日留存0.25活跃基本盘
Rev 近7日绿洲币消耗0.40商业价值

② 时间衰减 fd —— 新玩法保护

对"上架天数"惩罚：180 天内系数 a′ 从 0.0003 平滑升至 0.00055（温和）；180 天后加速逼近 0.00437，使 500 天处 fd≈0.5。新玩法 fd≈1。

fd = 1 / ( 1 + a′(days)·days )
分界 DAYS_MID=180；过渡宽度 K_LEFT=40 / K_RIGHT=400。

③ 规模衰减 fc —— 抑制大体量

对"近1年累计玩家数"惩罚：1500 万内缓慢、1500 万后加速，抑制超大体量老玩法"靠存量霸榜"。

fc = 1 / ( 1 + b′(cum)·cum )
分界 CUM_MID=1500万；过渡宽度 330万 / 3300万。

06结论
  • 新玩法获得公平机会：上架短、体量小的玩法 fd/fc≈1，靠近期热度与流水即可上榜（Top 15 中过半上架不足 100 天）。
  • 老玩法被温和降温：__OVER180__ 个玩法上架超 180 天，时间衰减 fd 起主导降温作用，加分项再高也会被显著压低。
  • 超级大体量被强抑制：近1年累计超 1500 万的仅 4 个玩法，规模衰减 fc 精准命中，避免"存量霸榜"。
  • 榜单反映"当前价值"：三因子相乘兼顾"扶持新玩法"与"抑制历史体量"双重导向。
